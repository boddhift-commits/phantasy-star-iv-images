# Phantasy Star IV HD - Godot Prototype

Modern HD port prototype of Phantasy Star IV using Godot 4.

## Features

- External JSON data (maps + dialogues)
- Grid-based movement
- NPC interaction + dialogue system
- Scalable rendering (HD-ready)
- Clean separation of engine / data / assets

## How to use

1. Download the full project from the conversation or recreate from the scripts below.
2. Open the folder in Godot 4.3+
3. Press F5

## Structure

- `scenes/` : Main, Field, DialogueUI
- `scripts/` : GDScript logic
- `data/` : JSON maps and dialogues
- `assets/` : placeholder for HD tilesets, sprites, audio

This is the foundation for a full HD remaster.
